## Controller

The website damiancehlarik.com is run by Damián Cehlárik, Bratislava, Slovakia. For any question about personal data, write to [mail@damian.works](mailto:mail@damian.works).

## What the website does not collect

The website uses no cookies, no visitor analytics, no advertising or tracking scripts, no forms, no comments and no embedded social media. The website uses a system typeface that is already on your device, so viewing a page does not connect your browser to any third-party server.

## Hosting

The website is hosted on GitHub Pages by GitHub, Inc. (USA). When you visit a page, GitHub logs your IP address and technical details of the request for security purposes and to protect the service. The controller has no access to these logs. Details are in the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). The legal basis is the legitimate interest in running the website securely (Art. 6(1)(f) GDPR).

## E-mail

If you write to the address above, your name, address and the content of your message are used only to reply and to continue the correspondence with you. They are kept as long as needed for that purpose. The mailbox is provided by Google (Google Workspace). The legal basis is the legitimate interest in replying to your message.

## Search statistics

The controller uses Google Search Console, which shows only aggregated data on how the website appears in Google Search. It contains no data on individual visitors, and there is no Google code on the website.

## Links to other websites

The website links to, for example, Instagram, ORCID, AFAD and Society. Once you follow a link, the privacy policy of that website applies.
